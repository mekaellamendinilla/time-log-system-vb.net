# Time Log System (VB.NET)

This is a simple Time Log System developed using VB.NET with a MySQL database.

## Features
- User login system
- Time in / Time out tracking
- Basic monitoring of employee logs

## Technologies Used
- VB.NET (Windows Forms)
- MySQL
- XAMPP (for database)

## How to Run
1. Install Visual Studio
2. Install XAMPP and start MySQL
3. Import the database (company_db.sql) using phpMyAdmin
4. Open the .sln file in Visual Studio
5. Run the project
